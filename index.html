// WHO WE ARE

Beyond the Code

We are an independent game development studio dedicated to merging human psychology, dystopian narratives, and melancholy through interactive experiences. We don't just build games; we craft haunting atmospheres that linger in the minds of players.

// CURRENT PROJECT

The Sleep:
Awakening

The Sleep: Awakening is an action-thriller tracking a journey from a mundane corporate routine to a dangerous struggle for survival. Powered by Unreal Engine 5, we fuse fluid parkour mechanics and combat dynamics within a gloomy city environment. Don't you see the state of the people? Perhaps it is time to wake up.

  • Unreal Engine 5
  • Parkour Traversal
  • Visceral Combat
  • Psychological Narrative
